NVLAP Asbestos Fiber Analysis laboratories

The National Voluntary Laboratory Accreditation Program (NVLAP), run by NIST, accredits laboratories that analyze asbestos with PLM and/or TEM. This page does not invent a lab table. The public directory is a search form; our fetch did not return rows without JavaScript. Use the official search, then confirm the lab code and expiration on the lab’s NVLAP page.

NIST Asbestos Fiber Analysis LAP page last updated 17 July 2026. Directory search retrieved 30 August 2026. No laboratory rows transcribed.

Use the official directory

Open NIST NVLAP Directory of Accredited Laboratories. Under Program, choose Asbestos Fiber Analysis. Under Country, choose United States (or another country). Press Search. Sort by city or state if the results table allows it. Click a lab name for the NVLAP lab code, address, phone if shown, accreditation scope, and expiration date.

What NVLAP accreditation covers

NIST: the Asbestos Fiber Analysis program “provides assurance that laboratories are competent to analyze asbestos samples using polarized light microscopy (PLM) and/or transmission electron microscopy (TEM).” The Asbestos Hazard Emergency Response Act (AHERA), enacted in 1986, requires that laboratories that analyze asbestos samples taken from public or private elementary or secondary schools be accredited by NVLAP.

Proficiency testing is mandated and provided by RTI International — biannually for PLM and annually for TEM, per the NIST program page. Labs are assessed against ISO/IEC 17025. Source: NIST Asbestos Fiber Analysis LAP (updated 17 July 2026).

This site is not a government agency and does not accredit laboratories or license asbestos contractors. Rows are transcribed from official federal and state sources cited on each page. Accreditation, licenses, phones, and expiration dates change. Confirm with the laboratory or contractor and with the issuing agency before you ship a sample or hire work.

EPA states that undamaged asbestos-containing material that will not be disturbed is usually best left alone, and that sampling done incorrectly can be more hazardous than leaving the material alone.
