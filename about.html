About Asbestos Lab Index

A directory by Stephen Shortell. We publish NVLAP laboratory guidance and public state asbestos-contractor lists. We do not invent records, rank abatement companies, or run live affiliate or click-to-call tracking on this version.

First version published 30 August 2026 (US/Pacific).

What we are

Asbestos Lab Index helps a U.S. homeowner find an NVLAP-accredited laboratory that can analyze asbestos, then a licensed contractor if the report says the material should be repaired or removed. It is not a government website, not a laboratory, and not an abatement contractor.

Methodology

  • Contractor rows are transcribed from official state PDFs or agency HTML lists. Each JSON record carries a source_url and document date.
  • If a field is not on the source (license number on the Kansas PDF, NVLAP scope when the directory does not return a row), we write unknown or omit it and link the official tool.
  • We do not copy business-directory phone numbers or “enrich” records from Google, Yelp, or company marketing sites.
  • We do not rank contractors. Tables keep the issuing agency’s order (or, for Pennsylvania, the agency table order after collapsing duplicate certification numbers to the later expiration date).
  • NIST’s public NVLAP directory is a JavaScript search form. This version could not retrieve a lab result table. We ship an honest explainer that links the official search rather than inventing laboratories.
  • Guidance pages quote or closely paraphrase EPA and NIST, with page dates. We do not invent EPA rules.
  • Call links (tel:) are included only when the official list already printed a phone number. There is no call-tracking number and no click-to-call vendor.

How to add a state: see README.md. What we fetched for this version: SOURCES.md.
